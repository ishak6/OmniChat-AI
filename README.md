23. চূড়ান্ত Project Design Principles

Maximum Freedom

OmniChat AI-এর মূল দর্শন

- AI নিজে সিদ্ধান্ত নেবে।

- সব ধরনের কাজে নিজে চেষ্টা করবে।

- নিজে Agent, Skill ও Tool ব্যবহার করবে।

- নিজে Android পরিচালনা করবে।

- নিজে পরিকল্পনা ও সমস্যা সমাধান করবে।

- অপ্রয়োজনীয় App-Imposed Limits থাকবে না।

- ব্যবহারকারীর নিয়ন্ত্রণ বজায় থাকবে।

- Android OS, API, হার্ডওয়্যার ও আইনগত সীমা মানতে হবে।
